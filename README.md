# Approximation and Optimization Theory for Linear Continuous-Time RNNs

**Bachelor's Thesis | Karlsruhe Institute of Technology (KIT) | October 2026**

This repository contains the code and numerical experiments for my bachelor's thesis on the approximation and optimization theory of linear continuous-time recurrent neural networks.

The thesis investigates the mathematical foundations of recurrent neural networks, with a focus on:

- Universal approximation properties of linear continuous-time RNNs
- Approximation rates and their dependence on network size
- Memory kernels and long-term dependencies
- Optimization and numerical experiments
